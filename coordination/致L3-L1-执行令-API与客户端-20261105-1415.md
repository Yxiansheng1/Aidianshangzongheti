## 一、目标与出处

给客户端一个稳定的本地接口，并把 Electron 壳立起来（本轮不做界面）。
依据：`docs/架构重构方案.md`（四层结构）与 `docs/并发分工.md`。

## 二、这一轮的范围（只做三步）

1. **FastAPI 薄壳**：`python -m pipeline.api` 起服务，默认 `127.0.0.1:8765`
   - `GET /api/health` → `{"ok": true, "version": ..., "tools": N}`
   - `GET /api/tools` → 读 `pipeline.harness.registry` 的工具清单（L2 还没交付时，先返回空列表，别去改 L2 的文件）
   - `GET /docs` 能打开（FastAPI 自带）
2. **Electron 壳**：`app/` 目录，用现成模板起（推荐 `guasam/electron-react-app`，Tailwind + shadcn 已配好）
   - 主进程启动时 spawn Python 服务，退出时 kill（含异常退出兜底）
   - 窗口里只放一个页面：显示 `/api/health` 的返回
3. **进程管理验证**：手动杀掉 Python，客户端能提示"后端断开"；重启客户端能重新拉起

## 四、判据

1. `.venv\Scripts\python.exe -m pipeline.api` 起来后，`curl http://127.0.0.1:8765/api/health` 返回 200
2. `pytest tests/test_api.py -q` 全绿（用 fastapi 的 TestClient，不需要真起端口）
3. `cd app && pnpm.cmd dev` 能开出窗口，窗口里显示后端状态
4. 杀进程后窗口显示"后端断开"（截图或日志为证）
