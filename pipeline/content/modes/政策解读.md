# 题材 · 政策解读（民生向）

> 这份管「写什么、不能写什么」，平台 skill 管「怎么写」。题材优先于平台默认结构。

## 一、只做这一件事

**把已公开的文件，翻成"对我有什么影响"。**

不是评论政策好不好，不是预测下一步，不是评价人。只回答三个问题：

1. 文件说了什么（一句）
2. **谁能享受、谁不能**（这是全文重点）
3. 具体是多少钱、什么时间、要什么条件

## 二、硬规则（违反任何一条，这篇作废）

1. **必须带原文**。没有官方原文（政府网 / 新华网 / 人民网 / 部委官网转载）就不许写。
   凭新闻标题写政策，等于编。
2. **限定条件原样保留**。凡是「每人 / 每月 / 最高 / 不超过 / 仅限 / 参加XX的」，
   原文怎么限定，正文就必须怎么写。
   > 原文：对参加城乡居民基本养老保险的 60 岁以上老人，每人每月提高 20 元
   > ❌ 60 岁以上老人每月涨 20 元
   > ✅ 参加城乡居民养老保险的 60 岁以上老人，每人每月涨 20 元
3. **不做政治评价**。不写"这个政策很及时""体现了…的决心"，也不写"这个政策没用"。
4. **不预测**。不写"下一步会怎样""可能还会涨"。
5. **不替人下结论**。把"你该不该交"改成"什么情况下值得交、什么情况下不划算"。
6. **不引无出处的"专家称 / 业内人士"**。要引就写清是谁、哪个机构、哪天说的。

## 三、结构（四段，顺序固定）

### ① 一句话说清改了什么（不超过 60 字）
先给最硬的那个变化：涨多少、扩到谁、什么时候开始。

### ② 谁受影响（核心段）
分三类写清：**能享受到的 / 不能的 / 情况特殊的**。
这一段决定这篇有没有用。漏掉"不能的"，就是误导。

### ③ 具体怎么算（给数字和条件）
- 钱：多少、按什么口径（月/年、含不含补贴、税前税后）
- 时间：从哪天起、要不要补缴、有没有过渡期
- 条件：参保类型、缴费年限、年龄、户籍、是否需要在职

### ④ 边界（什么情况下这条不适用）
至少写一条"如果你的情况是 XX，这个政策你享受不到"。

## 四、禁用词

```
重磅      炸了      突发      官宣（当噱头时）
据说      内部消息    知情人士（无出处的）
专家称    业内人士指出（无姓名机构的）
福利来了  赶紧去办    错过就亏
```

## 五、自检（答不上就重写）

1. 原文链接有没有？能不能指出这段话来自哪一段？
2. 我把限定条件全保留了吗？——把正文里那个数字单独拎出来看，会不会误导？
3. 有没有一句是我在评价政策好坏？有就删。
4. 读者看完，知道自己**能不能领、领多少**吗？

## 六、输出格式

沿用平台 skill 的 JSON 格式，另外在 `gaps` 里必须写清：
- 原文出处（哪份文件、哪天发布）
- 哪里是推算（例如按月折算成年）
- 哪些条件原文没写清
