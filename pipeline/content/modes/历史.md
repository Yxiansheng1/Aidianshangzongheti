# 题材 · 近代史与战史

> 只讲已经发生、且能查到的事。这份管边界，平台 skill 管写法。

## 一、能写什么

- 战役、事件、决策过程（有公开史料支撑的）
- 人物：将领、工程师、工人、普通人
- 工业史、基建史：三线建设、铁路、桥梁、工厂
- 老照片、老地图、旧文件背后的故事

## 二、不能写什么

1. **演义化**：不编对话、不编心理活动、不写"他心里想"
2. **美化战争**：不写战争的爽感，要写代价（伤亡、物资、普通人的日子）
3. **无据的细节**：具体到分钟的时间、精确到个位数的伤亡，没有出处就不写
4. **历史虚无 / 翻案**：不颠覆已有定论，不写"其实历史不是那样"
5. **牵扯当下的定性**：不借历史评论现实、不影射，不写"今天的 XX 也一样"

## 三、结构

### ① 钩子：一个具体细节（不是一句宏大判断）
从一张照片、一个数字、一件器物切入。
> "1958 年那台拖拉机下线时，车头上挂的是一块手写的木牌。"

### ② 背景：三句话说清"为什么会有这件事"
当时的条件、困难、决策背景。

### ③ 过程：关键节点 3–4 个
时间、地点、人、结果。每个节点一句。

### ④ 结局与代价
不写"胜利"两个字就完事。写清楚付出了什么、留下了什么。

### ⑤（可选）常见误传
"很多人以为是 X，其实是 Y"——这一条最容易涨收藏。

## 四、禁用词与禁用写法

```
惊天    震撼      秘闻     不为人知（当噱头）
真相是    其实历史不是这样
史诗级    封神     燃爆
```

也不写"据说当年""老人回忆"（没有具体出处时）。

## 五、自检

1. 细节里有几个是**编的**？编的一律删，或改成"据 XX 记载"。
2. 有没有一处写了战争的残酷或代价？
3. 时间、地点、人物名，能不能在维基或公开史料里对上？
4. 有没有影射当下？

## 六、输出格式

沿用平台 skill 的 JSON。`gaps` 里写清：哪些细节来自维基、哪些是多方记载不一致的、哪些没有出处。
