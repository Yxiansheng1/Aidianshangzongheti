# 题材 · 国际与军事观察

> 只讲公开信息。这份管边界，平台 skill 管写法。

## 一、能写什么

- 国际时事：外国政治、经济、冲突、外交——**只用公开报道**
- 军事：已公开的装备型号、编制体制、采购预算、战史
- 产业：造船、航空、能源、芯片等**公开的产能与预算数字**

## 二、不能写什么（违反即作废）

1. **国内时政**：人事、会议、政策评论——一条都不碰
2. **战争预测**：不写"下一步会开战""可能进攻""战术推演"
3. **未公开信息**：部队番号、具体部署位置、现役装备的实际参数、演习细节
4. **民族、宗教、领土争议的定性**：只陈述双方公开主张，不站边
5. **无出处的"外媒爆料""消息人士"**：要引就写清媒体名 + 日期
6. **煽动性动词**：击沉、毁灭、吊打、碾压、血洗、教做人

## 三、结构（四段）

### ① 发生了什么（一句，带时间地点）
不许铺垫，不许"近年来"。

### ② 关键数字 / 时间线（2–4 条）
预算、数量、交付时间、型号。**每个数字都要能在原文找到。**

### ③ 为什么重要（讲机制，不讲立场）
讲清"这件事改变了什么条件"：成本、产能、补给线、采购周期。
不写"这说明我们强大了""对手慌了"。

### ④ 已知的未知（必须写）
至少一条："原文没写 XX""这个数字没有第三方核实"。
这一段是这类内容唯一能建立信任的地方。

## 四、禁用词

```
开战说来就来   一战定乾坤   碾压    吊打    血洗
据外媒        消息人士称    有分析认为（无署名）
重磅          炸裂        彻底改变   颠覆
```

## 五、自检

1. 每个数字能在原文找到吗？找不到的删掉。
2. 有没有一句在预测下一步？有就删。
3. 有没有涉及国内时政？有就整段删。
4. "已知的未知"写了吗？

## 六、输出格式

沿用平台 skill 的 JSON。`gaps` 里必须写：消息来源（哪家媒体、哪天）、哪些是推算、哪些原文没写。
