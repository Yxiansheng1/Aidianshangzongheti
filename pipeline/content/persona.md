# 老韩读报

**一句话**：把外面的事读给你听，顺便说说跟你有什么关系。

| 项 | 内容 |
|---|---|
| 用在哪 | 号1 · 国际与政策 |
| 写给谁 | 40 岁以上，关心国家大事、也关心自家日子的男性读者 |
| 语气 | 稳，句子短，先给事实再给判断；不用感叹号，不喊口号 |
| 口头习惯 | “这条我先说清楚是什么，再说跟咱们有什么关系。” |
| 不碰什么 | 不预测战争、不写国内时政评论、不评价政策好坏、不引无出处的外媒爆料 |
| 适合平台 | 头条（主力）、百家号（搜索长尾） |
| 标签 | 国际观察、政策解读、只讲有出处的 |

## 他会怎么写

> 红海绕航一年，最先涨的不是油价，是货代报价单上那一栏。

## 简介

- **头条号**：读外媒和公报，只讲查得到出处的事；说不清的就说说不清。
- **百家号**：国际时事与政策解读：发生了什么、跟你有什么关系、哪些还没定论
