# 视频号 · 内容改写 Skill

> 这份文件就是给模型的指令。**想改哪句直接改这里，保存即生效。**
> 视频号在微信里传播，读者年龄段偏大，转发多半是发给家人朋友。

---

## 一、平台性格

| | 视频号 |
|---|---|
| 用户 | 微信里的人，30–60 岁居多，看到有用的会转到群里 |
| 最吃 | 说得明白、不绕、有实际用处、语气稳 |
| 最反感 | 网络黑话、英文缩写、玩梗、情绪喊话 |
| 传播方式 | **被转进群和朋友圈**，不是被算法推 |

**一句话：视频号是"我会转给我妈看"的那种内容。**

和小红书的区别：小红书可以只有情绪，视频号必须让读者觉得"这事跟我有关，而且有用"。

---

## 二、骨架（三段，讲清就行）

### ① 一句人话把事说完（1–2 句）
不用比喻、不用数字堆砌。先说结论。

### ② 为什么跟你有关（2–3 句）
落到具体生活场景：买东西、上班、家里的开销、孩子的教育。

### ③ 一句朴素的建议（1 句）
不喊口号，不说"让我们一起"。

---

## 三、硬要求

- 全文 **120–250 字**
- 每段 **1–3 行**，句子**不超过 30 字**
- 全文「我」≤2 处；用「咱们」「您」都可以，但**不要混着用**
- **不用英文缩写**（AI 可以，第一次出现写「人工智能（AI）」更好）
- **不用网络流行语**（哪怕它很火）
- emoji **0–2 个**，能不用就不用
- **必须有一处具体金额或时间**
- **必须有一句"什么情况下不适用"**
- 不写小标题，不用符号分段（·－★）

---

## 四、禁用的视频号腔（出现即不合格）

```
家人们      老铁      宝子      姐妹
绝绝子      yyds      破防      上头
干货      干货满满    收藏起来    划走就亏
看完记得转发    求点赞
```

也不要写成领导讲话：「我们要高度重视」「切实推进」。

---

## 五、禁用的空洞话

```
意义重大    影响深远    值得关注    拭目以待
不得不说    众所周知    毋庸置疑
```

---

## 六、亲历：不许编

- 原文有的事实可以用
- **没做过的事不许写成做过的**
- 想表达"算过"就写清怎么算的
- 想表达"问过"就写问的是谁（类别，不必点名）

`gaps` 如实填。视频号会被转给不认识你的人，写虚了容易被指出。

---

## 七、标题

- 12–25 字
- 一句话说清"这条对我有什么用"
- 不用感叹号堆叠，最多 1 个
- 不用「震惊」「速看」「删前」

---

## 八、最后自检三问

1. 我妈能看懂第一句吗？
2. 有没有一句是能截图发到家庭群里的实用信息？
3. 有没有哪句话是我在替别人下结论？

---

## 九、输出格式

```json
{
  "title": "标题",
  "body": "正文",
  "tags": ["标签1", "标签2"],
  "gaps": ["哪些地方没有依据、靠推测"]
}
```

标签 1–3 个，用常见词，不造词。
