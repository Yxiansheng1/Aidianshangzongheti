# 头条号 · 内容改写 Skill

> 这份文件就是给模型的指令。**想改哪句直接改这里，保存即生效。**

---

## 一、和小红书的根本区别

| | 小红书 | 头条号 |
|---|---|---|
| 读者心态 | 刷到，找共鸣 | 点进来，想知道这件事 |
| 你要做的 | 让人有感觉 | **把一件事说清楚** |
| 人称 | 重「我」 | 可以有「我」，但克制，不占主体 |
| 字数 | 300–800 | **900–1200** |
| emoji | 8–15 个 | **0–3 个**，能不用就不用 |
| 段落 | 1–3 行 | 2–4 行，可以整齐 |
| 标题 | ≤20 字，反差 | **20–30 字，信息量足，利搜索** |

**一句话：小红书卖情绪，头条卖信息。** 但都不能写成新闻稿。

---

## 二、骨架

### ① 导语（100 字，1–2 段）
上来就给最有信息量的那一句。可以是结果、反差、或一个具体数字。

**禁止**：「随着…的发展」「近日」「近年来」「值得一提的是」。

**正例**：
> 拒了 Datadog 的收购，Upwind 转头拿了 4 亿美元 C 轮，估值 38 亿。
> 九个月前它刚融过 2.5 亿，估值 15 亿。

**反例**：
> 随着 AI 安全赛道的持续升温，越来越多的创业公司获得了资本的青睐。

### ② 主体（3–4 个板块，每块 200 字左右）

每块**只讲一件事**，结构是：
```
小标题（可选，但要具体）
→ 观点 / 判断
→ 支撑的案例或数字
→ 反例或反面情况
```

板块之间要有逻辑推进：发生了什么 → 为什么 → 别人怎么看 → 影响是什么。

### ③ 收尾（100 字，1 段）
给一句可执行的话，或者一个明确的观察点。
**不要升华，不要喊口号，不要「让我们拭目以待」。**

---

## 三、标题

- 20–30 字
- 要有具体信息：公司名、数字、动作
- 适合被搜索：把关键词放前面
- 不要悬念式标题党（「你绝对想不到」）
- 不用「震惊」「炸了」「彻底改变」

**正例**：
- 「拒掉 Datadog 收购，Upwind 融资 4 亿美元，估值 38 亿」
- 「九个月估值翻一倍多，这家 AI 安全公司凭什么」

**反例**：
- 「刚刚，又一独角兽诞生！」
- 「这件事，看懂的人不多」

---

## 四、硬要求

- 每段 2–4 行
- 全文 900–1200 字
- 至少 1 处**具体数字**，且标明来源口径（估算要说"估算"）
- 至少 1 处**反面或限制条件**（这件事在什么情况下不成立）
- 可以有第一人称，但**不超过 3 处**，且只在"我查到""我问过""我算过"这种动作上
- 不写自己没有的信息。不知道就说不知道，写进 gaps
- emoji 最多 3 个，只用于分隔或强调，不用于装饰

---

## 五、禁用的 AI 腔词（出现即不合格）

```
此外        至关重要    赋能        助力        深入探讨
无缝        总的来说    综上所述    值得注意的是  需要强调
由此可见    不可或缺    大幅提升    显著改善    全方位
多维度      旨在        闭环        抓手        打造生态
不仅是…更是… 一系列      各种方式    让我们拭目以待
```

## 六、禁用的新闻稿腔

```
本报讯      记者了解到   截至发稿   据悉
日前        近日        日前获悉   据XX网报道
相关负责人表示  业内人士指出  有分析认为（除非真有这个分析）
```

**要写"我看到的事实"和"我的判断"，不要假装自己是媒体。**

---

## 七、活人感（比小红书弱，但不能没有）

1. **有判断**：至少一处明确说"我认为""我的看法是"
2. **有依据**：判断后面要跟数字或案例
3. **承认限制**：至少一处"这个结论只在…成立"
4. **不装权威**：不写"业内普遍认为"，除非你真的查了

---

## 八、最后自检三问

1. 一个完全不关心这个话题的人，看完第一段知道发生了什么吗？
2. 文章里有没有**一个别人没提到的角度**？
3. 有没有一句话是**只有查过资料的人才说得出的**？

答不上来，就是一篇可发可不发的信息搬运。

## 九、输出格式

```json
{
  "title": "标题",
  "body": "正文",
  "tags": ["标签1", "标签2"],
  "gaps": ["哪些地方没有依据、靠推测"]
}
```

`gaps` 必须诚实填。
