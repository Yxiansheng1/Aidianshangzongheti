# B站 · 内容改写 Skill

> 这份文件就是给模型的指令。**想改哪句直接改这里，保存即生效。**
> 这份只写**视频标题 + 简介**，B站是视频平台，没有图文长文形态。

---

## 一、平台性格

| | B站 |
|---|---|
| 用户 | 年轻，愿意看完 8 分钟，也愿意在弹幕里当场挑错 |
| 最吃 | 信息密度、自嘲、不装、承认"这块我不懂" |
| 最反感 | 电视腔、成功学、油腻亲切感、标题夸大后没兑现 |
| 简介作用 | 不是文案，是**让人决定点不点、看懂看不懂** |

**一句话：B站标题可以有梗，但简介必须诚实交代这视频里到底有什么。**

---

## 二、标题（15–35 字）

三种可用形态：

- **问题式**：「为什么四天的板子，比九天的还便宜」
- **数字+反差**：「差价 165 美元，只快 5 天」
- **自嘲式**：「我把报价算错了三次，才看懂这笔钱」

禁止：「全网首发」「万字解析」「你绝对不知道」「看完秒懂」。

**不要用过多的感叹号和书名号，最多一个。** 不要假装是大 UP 主。

---

## 三、简介骨架（100–300 字）

### ① 一句话说清这期讲什么（不要"本期视频"）
```
一块 4 层板，深圳报价 465 美元 9 天，加州报价 630 美元 4 天。
差 165 美元，我把这笔账拆了一遍。
```

### ② 给三个具体看点（列表，每条一句）
```
· 中位数 9 天意味着什么
· 为什么加州的贵不在人工
· 我算完之后改变的一个判断
```

### ③ 诚实交代缺口（1–2 句）
```
我没在这两家真的下过单，数据只有原文那一份报价单。
```

### ④ 一句弹幕钩子（可选，1 句）
留一个能被弹幕接住的问题。不作死、不带节奏。

---

## 四、硬要求

- 简介 **100–300 字**
- 每段 **1–3 行**，列表最多 4 条
- emoji **0–3 个**，用于列表前置符号可以，不用于句尾装饰
- 全文「我」可以用（B站接受第一人称），但**不许装作专家**
- **必须有一处具体数字**
- **必须有一处承认不懂或没验证**
- 不写"求三连""点赞过千"这类运营话

---

## 五、禁用的 B站腔（出现即不合格）

```
家人们      宝子      老铁
全网首发    万字解析    深度好文    干货满满
懂的都懂    建议收藏    看完你就不一样了
破防      绷不住     狠狠地
```

也不要玩梗过度：一条简介里最多一个梗，多了显得刻意。

---

## 六、亲历与数据：不许编

- 原文有的事实、数字可以用
- 视频里你实际做了什么（跑了一遍、算了账）可以写
- **没做过的实验、没测过的数据，一句都不许编**
- 引用别人的结论要写清"据原文"或"据XX的数据"

`gaps` 如实填：哪些是推测、哪些只对特定条件成立。

---

## 七、最后自检三问

1. 标题承诺的东西，简介里兑现了吗？
2. 有没有一句话能让懂行的人在弹幕里补充/纠正？（这代表你说得具体）
3. 有没有承认自己不懂的地方？

---

## 八、输出格式

```json
{
  "title": "视频标题（15-35 字）",
  "body": "简介正文（含看点列表与诚实交代）",
  "tags": ["标签1", "标签2"],
  "gaps": ["哪些地方没有依据、靠推测"]
}
```

标签 6–10 个，短词，别写句子。
