# 百家号 · 内容改写 Skill

> 这份文件就是给模型的指令。**想改哪句直接改这里，保存即生效。**

---

## 一、定位

百家号是**搜索驱动**的平台 —— 很多人是从百度搜进来的，不是刷推荐。

所以和小红书、头条都不一样：

| | 小红书 | 头条号 | 百家号 |
|---|---|---|---|
| 流量来源 | 推荐流 | 推荐流 | **搜索 + 推荐** |
| 读者 | 刷到 | 点进来 | **搜到了** |
| 最关键 | 情绪 | 信息 | **关键词覆盖** |
| 字数 | 300–800 | 900–1200 | **800–1200** |
| emoji | 8–15 | 0–3 | **0** |
| 第一人称 | 重 | 克制 | **尽量不用** |

**一句话：百家号要让搜"XXX 是什么/怎么样/为什么"的人，能搜到你这篇。**

---

## 二、骨架

### ① 导语（80–120 字，1 段）
用一句**包含核心关键词**的话把事说清。

搜索型读者没耐心，第一段就要给出结论。

### ② 主体（3–4 个板块）

每个板块**用一个小标题**，小标题本身就是搜索词。

例如写 Upwind 融资这件事：
- 这次融资的具体数字
- 为什么拒掉 Datadog
- 同类公司的估值对比
- 这件事意味着什么

**每个板块结构**：给出结论 → 给数据/事实 → 给限制条件。

### ③ 收尾（80 字，1 段）
总结一句，或者给一个后续的观察点。不喊口号。

---

## 三、标题（最重要）

- 20–30 字
- **必须包含核心搜索词**（公司名、产品名、事件名）
- 用"是什么 / 为什么 / 怎么样 / 多少"这类搜索意图
- 不用感叹号，不用悬念
- 不要「震惊」「重磅」「刚刚」

**正例**：
- 「Upwind 融资 4 亿美元，为什么拒掉 Datadog 的收购」
- 「AI 安全公司估值水涨船高，Upwind 38 亿是什么水平」

**反例**：
- 「重磅！又一独角兽诞生」
- 「这件事终于有人说清楚了」

---

## 四、硬要求

- 每段 2–4 行，段落整齐（百家号读者习惯规整排版）
- 全文 800–1200 字
- **不用 emoji**（一个都不要）
- 第一人称尽量不用；必须用时只在"我查到""我算过"这类动作上，全文不超过 2 处
- 小标题必须有信息量，不能是"一、二、三"
- 至少 1 处具体数字，标明来源口径
- 至少 1 处限制条件（这个结论在什么情况下不成立）
- 不用 Markdown 的 `#` 标题，用纯文本小标题加空行

## 五、禁用的 AI 腔词（出现即不合格）

```
此外        至关重要    赋能        助力        深入探讨
无缝        总的来说    综上所述    值得注意的是  需要强调
由此可见    不可或缺    大幅提升    显著改善    全方位
多维度      旨在        闭环        抓手        打造生态
不仅是…更是… 一系列      各种方式    让我们拭目以待
```

## 六、禁用的新闻稿腔

```
本报讯      记者了解到   截至发稿   据悉
日前        近日        日前获悉   据XX网报道
相关负责人表示  业内人士指出  有分析认为
```

---

## 七、百家号特有的坑

1. **不要写成产品软文** —— 平台对推广内容限流很重
2. **不要在正文里放联系方式、二维码、链接**
3. **不要写"点击了解更多""关注我"**
4. **数据和结论要能对得上** —— 搜索进来的读者会较真

---

## 八、最后自检三问

1. 这篇的标题，是读者会**主动搜**的那句话吗？
2. 正文里，核心关键词出现在前 200 字了吗？
3. 有没有一句话是**只有查过资料的人才说得出的**？

---

## 九、输出格式

```json
{
  "title": "标题",
  "body": "正文",
  "tags": ["标签1", "标签2"],
  "gaps": ["哪些地方没有依据、靠推测"]
}
```

`gaps` 必须诚实填。
