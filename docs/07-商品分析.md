# 商品分析

## 它做什么

你丢一个商品进去，出来四样东西：

1. **商品分析** —— 定位、人群、卖点、差异点、售后风险、定价、搜索词、值不值得做
2. **生图提示词** —— 5 条，直接粘到「出图」页就能跑
3. **视频提示词** —— 2 条，直接粘到「视频」页
4. **小红书文案** —— 标题 + 正文 + 标签

GUI 里每条提示词旁边有「用这条出图 / 用这条出视频」按钮，点了自动填好并跳页。

---

## 先接受一个现实：链接基本抓不到

| 平台 | 未登录能抓到什么 |
|---|---|
| 淘宝 / 天猫 | 基本抓不到，要登录 |
| 1688 商品页 | 抓不到，内容 JS 动态渲染（已实测） |
| 小红书 | 抓不到，需要登录态 + 有反爬 |
| 京东 | 偶尔能拿到标题 |

`pipeline fetch` 只发一个普通 GET，从 meta 标签里抠标题/描述/价格。失败会明确告诉你失败，**不会硬爬**——爬虫除了法律风险，还会把你的 IP 搞脏。

**所以正确的用法是：链接 + 手动补。** 你在商品页复制标题、参数、卖点，粘进「页面描述」，比什么都靠谱。

---

## 需要文本模型

这部分靠判断，不能靠模板拼。所以必须有 `config.toml` 里的 `[model]`：

```toml
[model]
base_url = "https://api.deepseek.com"
api_key = "sk-..."
text_model = "deepseek-chat"
```

DeepSeek 充 10 块够分析几百个品。

## 用法

### 界面

页签「分析」→ 填商品名（必须）+ 描述（强烈建议）→ 开始分析。

### 命令行

```powershell
# 只看会发给模型的提示词，不花钱
python -m pipeline analyze --name "渐变杯装蜡烛" `
    --desc "手作大豆蜡，燃烧约25小时，渐变玻璃杯身" --dry-run

# 真跑
python -m pipeline analyze `
    --url "https://detail.1688.com/offer/xxx.html" `
    --name "渐变杯装蜡烛" `
    --price "售价89，代发32" `
    --desc "手作大豆蜡，燃烧约25小时，渐变玻璃杯身，无烟配方" `
    --extra "三家现货代发，竞品卖79-99"
```

输出到 `output/分析/商品名.md`，同时存一份 `.json`。

## 提示词为什么这么写

模型是「参考图生图」，商品本身会原样保留。所以提示词**只描述环境和拍摄方式**，不描述商品长什么样。

这一点很反直觉：你写「一个米白色的圆润玻璃瓶」反而会让商品变形。正确写法是：

```
浅色橡木桌面，左侧窗光斜射，浅景深，背景虚化，
商品居中占画面 60%，轻微俯视角度，商品保持原样不变形
```

五条固定的拍摄方向：白底主图 / 生活场景 / 细节特写 / 平铺组合 / 真人使用。覆盖一个商品上架需要的全部主图位置。

视频提示词更受限：图生视频只有一张起始图，**不能描述画面里出现新东西**，只能写镜头运动 + 光线变化。

## 分析结果的可靠度

| 字段 | 可信度 | 说明 |
|---|---|---|
| 定位 / 人群 / 卖点 | 较高 | 纯文本推理，模型擅长 |
| 生图 / 视频提示词 | 高 | 可直接用 |
| 售后风险 | 中 | 能想到常见坑，但不懂你的具体供应链 |
| **定价建议** | **低** | 模型不知道你的实际成本和竞品价格，只能给区间**参考** |
| **值不值得做（verdict）** | **低** | 没有真实销量数据，判断是猜的 |

**最后两条必须自己判断。** 真正的选品判断在 `docs/05-选品口径.md` 的打分表里，那套口径是你自己的，比模型靠谱。
