# 选品口径

## 这个模块能做到什么、做不到什么

**能做到**：把你手动收集的候选品，按固定口径打分排序，避免在几个"看着都不错"的品之间反复摇摆两周。

**做不到**：自动发现好品。平台没有合法接口，抓取会封号。市面上号称"一键选品"的工具，要么数据是买的（飞瓜/蝉妈妈，年费几千起），要么是爬的（违规）。

**所以：数据你收集，模块负责判断。** 这个分工不会变。

---

## 七个维度

每项 1–5 分，加权后满分 100。权重按「兼职 + 零货源 + 零背景」定。

| 维度 | 权重 | 1 分 | 3 分 | 5 分 |
|---|---|---|---|---|
| 竞争度 | 20 | 前 20 名全是天猫旗舰店 | 天猫和 C 店各半 | 前 20 名有多家普通 C 店 |
| 毛利空间 | 15 | 毛利率 < 15% | 25% 左右 | > 40% |
| 售后省心 | 15 | 易碎/有色差/会过敏 | 偶有退换 | 几乎无售后 |
| 低咨询 | 12 | 买家天天问怎么用 | 偶尔问 | 看图就能下单 |
| 供应链稳定 | 13 | 只有 1 家代发、发货慢 | 1–2 家有货 | 3 家以上现货 |
| 视觉可差异化 | 15 | 同行主图都很精致 | 能拍平手 | 换场景/组合就能赢 |
| 复购潜力 | 10 | 一辈子买一次 | 一两年一次 | 消耗品，季度内复购 |

## 评级线

| 总分 | 评级 | 动作 |
|---|---|---|
| ≥ 75 | 主推 | 拿样、实拍、上架 |
| 60–74 | 备选 | 备用，主推不成立时再动 |
| 45–59 | 观察 | 别投钱 |
| < 45 | 放弃 | 换一批 |

## 一票否决

只要勾中任意一项，**分数再高也直接淘汰**：

`license` 需资质 · `brand` 品牌侵权风险 · `fragile` 易碎易变形 ·
`size` 有尺码/规格争议 · `heavy` 超重超尺寸 · `custom` 需定制 · `ban` 平台限售

对你这个条件（兼职、没时间处理售后），**否决项比分数重要**。一个 85 分但要资质的品，等于 0 分。

## 毛利怎么算

```
单件毛利 = 售价 − 代发成本(含运费) − 售价 × 1.2%(平台扣点) − 退货率 × 10 元(退回成本)
毛利率   = 单件毛利 ÷ 售价
```

退货损耗按每单 10 元估（运费 + 包装 + 折旧）。退货率按类目估，服装类要算 30–40%。

## 用法

```powershell
# 1. 生成候选池模板
python -m pipeline pick init

# 2. 用记事本打开 candidates.toml，把候选品填进去

# 3. 排序
python -m pipeline pick rank
python -m pipeline pick rank --top 2
```

输出示例：

```

-  -------------------  ----  ----  ----  ------  ---------------
1  渐变杯装蜡烛         79.0  主推    89   61.9%                —

3  纯棉短袖T恤（反例）  46.2  淘汰    59   45.4%  有尺码/规格争议

建议先拿样：渐变杯装蜡烛（79.0 分 / 主推 / 单件毛利 ¥55.1）
```

## 三条纪律

1. **候选少于 5 个不做结论。** 三个品里挑最好的，挑出来的通常是"最不差的"，不是"好的"。
2. **只拿前 2 名的样。** 超过 3 个品的样品钱，就是在浪费。
3. **打分表和 HTML 版口径一致**（`选品打分表.html`），任选一个用，别两边都填。
