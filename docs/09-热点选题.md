# 热点选题

每天自动抓一次热点，国内 + 国外，分四类给你一份**菜单**。

## 核心设计：两层，别混

| 层 | 内容 | 用途 |
|---|---|---|
| **推荐蹭的** | 类目命中 + 非负面 | 直接能用 |
| **完整菜单** | 抓到的全部，按分类 | 自己判断 |

为什么要分开：**你想看军事新闻，但「战争/导弹/袭击」在负面词表里。**
如果只输出推荐层，军事类会全军覆没。所以菜单层必须全量。

菜单里每条都打标记：`相关` / `负面` / 空白（与类目无关）。

**不支持的**：知乎（401）、抖音（要签名）、Reuters（404）、小红书（反爬 + 违规）。

**网络**：国内源直连（代码里明确 `ProxyHandler({})` 绕开系统代理），
国外源走 `config.toml` 的 `[trends] proxy`，默认 `http://127.0.0.1:7897`。

单个源挂了不影响其他，错误会列在输出顶部。

## 两道过滤（只作用于"推荐层"）

### ① 关键词匹配

中文按子串，**英文按词边界**。

> 这里踩过一个坑：一开始英文也用子串匹配，结果「AI」命中了
> `cl**ai**ms`、`f**ai**lure`、`F**ai**th`，一堆政治新闻被标成"AI 相关"。
> 短英文词必须用 `(?<![A-Za-z])AI(?![A-Za-z])` 这种词边界正则。

默认关注词（`pipeline/trends.py` 的 `DEFAULT_KEYWORDS`）：

```
家居 收纳 整理 香薰 香氛 蜡烛 氛围 租房 独居 小户型 桌面 改造
好物 生活 卧室 书房 厨房 礼物 送礼 平价 懒人 宿舍
情绪 解压 治愈 松弛 仪式感 宅家 冬天 降温
AI 人工智能 设计 创意 手作 DIY
```

可以在 `config.toml` 里用 `[trends] keywords = [...]` 覆盖。

### ② 负面过滤

**中英双语**，缺一个就会漏。

中文：身亡 遇袭 死亡 事故 火灾 车祸 被捕 判刑 谣言 诈骗 离婚 出轨 恋情 疫情 暴雪 台风 战争 导弹 …

英文：kill dead death crash attack war missile shooting hack leak scandal fraud arrested jailed layoff bankruptcy collapse crisis flood earthquake pandemic cancer …

> 踩过的坑：负面词只写了中文时，「Spain train crash kills at least 68」和
> 「US immigration agents leaked in major hack」都进了推荐栏。

**蹭正面热点叫借势，蹭负面叫找死。**

## 用法

```powershell
python -m pipeline trends                      # 全抓
python -m pipeline trends --save               # 顺便存 md
python -m pipeline trends --category "AI与科技"  # 只看一类
python -m pipeline trends --sources hn,arxiv    # 只看指定源
```

接口：

```
GET http://127.0.0.1:8899/api/trends?save=1
GET http://127.0.0.1:8899/api/trends?categories=AI与科技,军事
```

n8n：`workflows/热点选题.json`，每天 08:00 自动跑，结果存 `output/热点/日期.md`。

## 怎么用这份菜单

1. 先看「推荐蹭的」，有合适的直接用
2. 没有就翻「完整菜单」，按分类扫
3. 挑中了 → 复制标题，丢进工作台「分析」页签的补充信息
4. 让 AI 想结合点，再出图写文案

**别硬蹭。** 关联不上就别用，生硬蹭热点比不蹭更伤账号。

## 2026-10-30 新增两组源（给两个头条号用）

原来 21 个源只覆盖新闻热点，**没有政策和历史**。两个头条号分别需要这两块，所以各加一个源：

| 分类 | 源 | 实现 | 实测 |
|---|---|---|---|
| **政策** | 国务院政策 | 读 `gov.cn/zhengce/` 原始 HTML，抠 `zhengce/content/*.htm` 链接 | 5 条，全部带原文链接 |
| **历史** | 维基·历史上的今天 | `zh.wikipedia.org/api/rest_v1/feed/onthisday/events/月/日`，只留中国/战史/工业方向 | 50 条 → 筛出 15 条 |

**政策源的两个坑**（都已处理）：
- 政策频道首页能抓，但 `zhengce/zuixin/`（最新政策列表）是 JS 渲染，抓不到
- 正文提取器会把链接全过滤掉，所以索引页必须读原始 HTML 自己解析

**历史源的天花板**：每天 50 条里多数是外国事件，筛完 2–4 条能写。所以历史号靠
**题库**（`pipeline/content/topics/历史题库.md`，40 题，词条已逐个核过存在），
「历史上的今天」只当补充。

```powershell
# 只看政策 / 历史（命令行 --category 一次一个分类）
python -m pipeline trends --category 政策
python -m pipeline trends --category 历史
```

接口支持多分类：`GET /api/trends?categories=政策,历史`。
