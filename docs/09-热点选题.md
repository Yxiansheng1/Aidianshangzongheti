# 热点选题

每天自动抓一次公开热搜榜，筛出跟你类目相关的，过滤掉不能蹭的。

## 它解决什么

"今天发什么" 这个每天都要面对的空白。

## 数据源（2026-10-29 实测）

| 来源 | 状态 | 说明 |
|---|---|---|
| **百度热搜** | ✅ 51 条 | 榜单藏在 HTML 注释 `<!--s-data:{...}-->` 里 |
| **微博热搜** | ✅ 51 条 | 必须带 `Referer` 头，否则 403 |
| 知乎热榜 | ❌ 401 | 要登录态 |
| 抖音热点 | ❌ | 需要签名 |
| 小红书 | ❌ | 反爬 + 违规，不碰 |

抓不到就跳过，不重试、不绕。少一个源不影响用。

## 两道过滤

### ① 关键词筛选

默认关注词（`pipeline/trends.py` 里的 `DEFAULT_KEYWORDS`）：

```
家居 收纳 整理 香薰 香氛 蜡烛 氛围 租房 独居 小户型 桌面 改造
好物 生活 卧室 书房 厨房 礼物 送礼 平价 懒人 宿舍
情绪 解压 治愈 松弛 仪式感 宅家 冬天 降温
```

**这一步很关键。** 一开始只写了「香薰」，而当天榜单上的是「香**氛** 年轻人的情绪搭子」——差一个字就没匹配上。真实类目的词都得覆盖。

### ② 负面过滤

命中任意一个词直接丢弃：

```
身亡 遇袭 死亡 去世 猝死 轻生 崩溃 事故 火灾 爆炸 车祸 殴打
被捕 判刑 起诉 拘留 处罚 谣言 诈骗 离婚 出轨 恋情 道歉 争议
确诊 感染 疫情 癌 暴雪 暴雨 台风 地震 战争 冲突 …
```

**为什么必须有这道**：实测抓到过「男子服务区情绪崩溃 交警接力护送」——靠「情绪」命中的，但这是绝对不能蹭的新闻。

**蹭正面热点叫借势，蹭负面叫找死。**

## 排序

```
分数 = 命中关键词数 × 100 + (51 - 排名)
```

命中越多、排名越前，越靠前。命中 0 的不进列表。

## 用法

### 命令行

```powershell
python -m pipeline trends                 # 看今天的
python -m pipeline trends --top 5 --save  # 存一份 md
python -m pipeline trends --sources baidu # 只抓百度
```

### 接口

```
GET http://127.0.0.1:8899/api/trends?top=10&save=1
```

返回 JSON，`hot` 是命中列表，`markdown` 是排好版的文本。

### n8n 自动跑

`workflows/热点选题.json` —— **每天 08:00** 自动执行：

```
每天8点 → 抓热点 → 有热点吗 ─┬─ 有 → 挑出来了（含 top1）
                              └─ 无 → 今天没有
```

结果写到 `output/热点/YYYY-MM-DD.md`。

想改时间：双击「每天8点」节点。

## 实际命中率（说实话）

每天 100 条热搜里，跟家居/香薰类目相关的通常 **0–3 条**。

原因很简单：热搜榜以时政、娱乐、体育为主，生活类目本来就是小众。

**所以这个功能的价值不是"天天有热点蹭"，而是：**

1. 每天 10 秒扫一眼，有就顺手用
2. 没有的时候不浪费时间瞎想
3. 偶尔撞上一条（比如今天这条香氛），就是白捡的流量

## 抓到之后怎么用

1. 挑一条能跟你商品搭上的
2. 复制标题，丢进工作台「分析」页签的**补充信息**
3. 让 AI 想一个结合点（"这个热点和香薰蜡烛怎么关联"）
4. 出图 + 写文案

**别硬蹭。** 关联不上就别用，生硬的蹭热点比不蹭更伤账号。
