### C6 的实际结论（2026-10-28）

发布**没有成功**，但也不是代码问题：

| 环节 | 结果 |
|---|---|
| cookie 认证 | ✅ |
| 进入发布页 | ✅ |
| 上传图片 | ✅ |
| 填标题 / 正文 / 话题 | ✅ |
| 来源转载声明 | ✅ |
| **点「发布」** | ❌ 页面 Toast：**「未绑定手机号」** |

**小红书对未绑定手机号的账号不放行发布。** 绑手机号之前，这条链路走到最后一步必然失败。

同时发现两个上游问题，已在本地 `D:\social-auto-upload` 打补丁：

1. **无限重试**：`while True` 无重试上限，失败时永远不退出（第一次跑了 10 分钟被我超时杀掉）
   → 改为 6 次上限，失败时保存 `logs/publish_fail.png` + `.html`
2. **遮罩弹窗**：页面会出现「图片可以编辑啦」+「我知道了」的浮层，拦截点击
   → 重试前先尝试关闭

补丁只在本地，没有进上游仓库。升级 sau 时会被覆盖，需要重新打。
