# API Key 说明

只需要两类 key：**出图的** 和 **写字的**。

---

## 一、图像模型（关键，选错就白干）

### 唯一的硬条件

**必须支持「参考图输入 / 图像编辑」，不能是纯文生图。**

纯文生图的模型会把你上传的商品「重新画一遍」，结果就是：形状不对、logo 变形、材质跑偏。这种图不能做主图。

判断方法：文档里出现 `image edit`、`参考图`、`图生图`、`reference image` 这类词，才算合格。

### 可选方案

| 方案 | 大概价格 | 说明 |
|---|---|---|
| GPT-Image 系列 | 约 0.3–0.5 元/张 | 效果最稳，需要外网 + 美元结算 |
| 即梦 / 豆包（火山引擎） | 约 0.1–0.3 元/张 | 国内直连，备案友好 |
| 通义万相（阿里云） | 约 0.1–0.3 元/张 | 国内直连 |
| 可灵（快手） | 约 0.3 元/张起 | 强项是视频 |

> 价格是估算，随时会变，以官网为准。

**建议**：先用最便宜的一家跑通流程，图不满意再换贵的。不要在第一步就追求画质。

### 12 张图的成本

一个商品按 4 头图 + 8 详情屏算，约 12 张：

- 便宜方案：约 2–4 元
- 贵的方案：约 5–7 元

**一天做 3 个品，月成本 200–600 元。** 这是可接受的范围。视频才是真正的成本黑洞，暂时别碰。
